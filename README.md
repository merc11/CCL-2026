# 第一届低资源缅甸语固定模版语句推理评测
**(The 1st Low-Resource Burmese Fixed Template Sentence Inference Evaluation)**

![Static Badge](https://img.shields.io/badge/CCL_2025-Evaluation_Task-blue) ![Static Badge](https://img.shields.io/badge/Language-Burmese-green) ![Static Badge](https://img.shields.io/badge/Parameters-under_14B-orange)

欢迎来到 **第一届低资源缅甸语固定模版语句推理评测**！本评测任务旨在推动机器翻译与大语言模型（LLMs）在低资源语言特定垂直场景下的深度理解与应用。

---

## 1. 任务简介

在缅甸语等低资源语言的翻译中，固定模版语句的推理作为垂类的任务，其语言内部的词性、地名、多元价值观等显著影响着最终的翻译质量。

* **格式与习惯差异**：例如，中文的“第1名”、“第3章”，在缅甸语意为“编号”或者“号”，后面需要紧跟缅甸语数字。
* **地名转写冲突**：地名转写往往与缅甸语特有发音、历史习惯冲突，导致中文直接转写容易出现混乱。
* **多元价值观影响**：翻译受种族、宗教以及集体主义的影响，不能简单直译。必须充分考虑当地的文化敏感性和宗教背景，否则极易引起误解或反感。

作为固定模版语句的推理任务，机器具体要适应的是**模版格式**、**幻觉处理**等任务的重要形式依据。为了提升翻译大模型在缅甸语上的翻译质量，进一步实现机器对人类固定模版语句的深度理解，我们正式推出本次评测任务。

## 2. 评测关注点

本次评测主要关注以下两方面的核心问题：

1. **模型表现差异**：LLMs 的缅甸语固定模版语句推理表现如何？不同 LLMs 在不同语境条件下的表现有何差异？
2. **提示词工程影响**：不同的提示词（Prompts）编写方式（包括但不限于更改 shots 数量、使用 CoT 思维链、更改提问句式等）对 LLMs 的推理结果会产生何种影响？什么样的提示词设计可以最大程度上优化 LLMs 的缅甸语固定模版语句推理表现？

## 3. 参赛规则与模型要求

* **自主设计与选择**：参赛队伍需要根据所提供的测试集自行设计提示词，自主选择合适的模型参加测试。
* **参数量限制**：为满足边缘部署与实际应用需求，**模型大小限定必须小于 14B**（鼓励采用 8B 及以下的轻量级模型）。
* **调用方式**：参赛队伍需通过 API 方式向模型提问并获取回答。
* **开放探索**：此次评测在大模型的选择、提示词的设计方式与具体的提问方式上均不设限制，鼓励尝试进行多样化、复合化测试手段以获得更好的回答表现。

## 4. 评价标准

为确保结果可比、可复现、可验证，我们将建立多维度评测机制：

| 评测维度 | 指标/方法 | 说明 |
| :--- | :--- | :--- |
| **翻译与推理质量** | BLEU (SacreBLEU), COMET | 考察模型输出内容在模板契合度、文化敏感度及语义准确性上的表现。 |
| **模型轻量化指标** | 参数量、模型文件大小 | 模型须 < 14B。若模型参数量 ≤ 2B 或文件大小较小（如 ≤ 4GB）将作为参考优势。 |
| **推理效率** | 平均延迟 (ms), 吞吐量 (tokens/s) | 考察模型响应的敏捷度。 |

*(注：具体的官方评分脚本和基线结果将在后续测试集发布时同步更新。)*
